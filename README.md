# Food Order App

A responsive, accessible food ordering website built with HTML, CSS, and JavaScript. This application allows users to browse sweet and savoury dishes, add items to a shopping cart, and request quotations.

## Features

### Home Page
- **Hero Carousel**: Rotating banner showcasing featured content
- **Featured Dishes**: Categorized menu with sweet and savoury items
- **Shopping Cart**: Add items to cart with quantity controls
- **Reviews Section**: Customer testimonials and review submission form
- **Responsive Design**: Mobile-first approach with optimized layouts for all screen sizes

### Contact Page
- **Contact Form**: Get in touch with subject selection and message
- **Contact Information**: Phone numbers, email addresses, and business hours
- **Google Maps Integration**: Interactive map showing location
- **Multiple Contact Methods**: Phone, email, and address information

### Shopping & Quotation
- **Add to Cart**: Simple interface to add dishes to cart
- **Cart Management**: View, update quantities, and remove items
- **Quotation Request**: Submit cart for custom quotation with delivery details
- **Local Storage**: Cart persists across browser sessions

### Accessibility Features
- Semantic HTML5 elements
- ARIA labels and roles
- Keyboard navigation support
- Focus indicators
- Screen reader friendly
- Reduced motion support for users who prefer it

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No build tools or dependencies required

### Installation

1. Clone the repository:
```bash
git clone https://github.com/huzrulz/food-order-app.git
cd food-order-app
```

2. Open in browser:
   - Simply open `index.html` in your web browser
   - Or use a local server like Live Server for development

## Usage

### Browsing Dishes
- Navigate to the home page
- Scroll to the "Featured Dishes" section
- Browse sweet and savoury categories

### Adding to Cart
1. Click "Add to Cart" on any dish
2. Click the shopping cart icon in the navigation
3. Adjust quantities using +/- buttons
4. Remove items using the trash icon

### Requesting a Quotation
1. Add items to your cart
2. Open the cart modal
3. Click "Get Quotation"
4. Fill in your contact details and preferences
5. Submit the quotation request

### Submitting a Review
1. Scroll to the reviews section
2. Fill in your name, rating, and review
3. Click "Submit Review"

### Contacting Us
1. Navigate to the Contact page
2. Fill in the contact form with your details
3. Submit your message
